8×8 RAM in Verilog

A simple 8×8 RAM (Random Access Memory) module written in Verilog HDL. This project demonstrates the implementation of a small synchronous memory with separate read and write operation.
Features
1. 8 memory locations
2. 8-bit data width
3. Synchronous write operation
4. Read operation through a read address
5. Reset functionality to initialize memory
6. Written in synthesizable Verilog
